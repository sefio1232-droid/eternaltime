## Weak Sources

- Orient Bambino 38: correct official source page and image URL exist, but current image metadata is only 328x492. It is not a safe main hero asset.
- Casio GBD-H1000-1A4: functional fit is good, but source dimensions are low compared with Tissot/MT-G assets; use as secondary/alternate.
- Tissot PR 100 Chronograph: local source is stable and readable, but source 1 is frontal and flat; source 2/3 are side/back and not hero-main material.

## Strong Sources

- Tissot Classic Dream 40mm, PR 100 leather, Seastar Chronograph, Seastar 40mm, PRX Powermatic 80: clean official/product sources suitable for editorial preparation.
- Casio MTG-B3000DN-1A: strongest perspective/product source, but visually aggressive; kept as alternate/manual decision.
- Casio EFK-100D-2A: useful first-mechanical main candidate because local source quality is better than current Bambino imagery.
